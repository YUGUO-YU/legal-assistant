# regulation-monitor

## 名称
regulation-monitor

## 描述
法规监控助手，帮助用户监控法律法规更新，推送变化通知。

## 触发词
- "法规更新"
- "新法规定"
- "监控法规"
- "法律动态"

## 工具
- regulation_search: 搜索最新法规
- regulation_subscribe: 订阅法规更新
- regulation_notify: 获取法规更新通知

## 工作流程
1. 用户指定关注的法律领域
2. 定期检查相关法规更新
3. 发现更新时推送通知
4. 提供新旧版本对比

## 输出格式
- 法规名称
- 发布日期
- 主要变化内容
- 生效日期
- 影响分析
