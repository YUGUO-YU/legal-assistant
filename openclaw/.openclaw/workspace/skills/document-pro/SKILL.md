# document-pro

## 名称
document-pro

## 描述
文档专业处理工具，帮助用户处理、转换和提取文档内容。

## 触发词
- "处理文档"
- "转换格式"
- "提取内容"
- "文档处理"

## 工具
- document_parse: 解析文档内容
- document_convert: 转换文档格式
- document_extract: 提取关键信息

## 支持的文档类型
- PDF
- Word (.docx)
- Excel (.xlsx)
- TXT
- Markdown

## 工作流程
1. 用户上传或提供文档
2. 选择处理方式（解析/转换/提取）
3. 执行处理
4. 返回结果

## 输出格式
- 解析结果：文档内容和结构
- 转换结果：目标格式的文件
- 提取结果：关键信息摘要
