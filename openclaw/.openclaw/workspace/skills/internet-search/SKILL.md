# internet-search

## 名称
internet-search

## 描述
互联网全网搜索工具，帮助用户进行深度信息检索，获取全面的网络资源。

## 触发词
- "全网搜索"
- "网上搜一下"
- "深度搜索"
- "全网信息"

## 工具
- internet_search: 执行深度搜索
- internet_news: 获取最新资讯
- internet_trend: 获取趋势分析

## 工作流程
1. 用户提供搜索关键词
2. 调用 internet_search 进行全网搜索
3. 汇总和筛选结果
4. 提供详细的搜索报告

## 输出格式
- 搜索结果摘要
- 来源分布统计
- 热点趋势分析
- 相关推荐
