# mova-contract-generation

## 名称
mova-contract-generation

## 描述
合同智能生成助手，根据模板和参数自动生成法律合同。

## 触发词
- "生成合同"
- "起草合同"
- "帮我写一份合同"
- "合同模板"

## 工具
- contract_templates: 获取合同模板列表
- contract_generate: 根据参数生成合同
- contract_customize: 自定义合同条款

## 支持的合同类型
- 房屋租赁合同
- 劳动合同
- 买卖合同
- 租赁合同
- 委托合同
- 合作合同

## 工作流程
1. 确定合同类型
2. 收集必要参数（当事人信息、标的、期限等）
3. 选择或创建模板
4. 生成合同草稿
5. 提供下载或复制

## 输出格式
- 完整的合同文本
- 关键条款摘要
- 编辑建议
