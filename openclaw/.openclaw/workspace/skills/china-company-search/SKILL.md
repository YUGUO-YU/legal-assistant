# china-company-search

## 名称
china-company-search

## 描述
中国企业信息查询助手，帮助用户查询企业工商信息、股东穿透和风险评估。

## 触发词
- "查询企业"
- "企业信息"
- "公司工商信息"
- "股东穿透"

## 工具
- company_search: 搜索企业
- company_detail: 获取企业详情
- company_shareholders: 获取股东信息
- company_risk: 获取企业风险信息

## 工作流程
1. 用户提供企业名称或关键词
2. 调用 company_search 搜索企业
3. 选择目标企业获取详细信息
4. 分析股东结构和风险状况

## 输出格式
- 企业基本信息（名称、信用代码、法人等）
- 股东信息及持股比例
- 工商变更记录
- 风险信息（行政处罚、诉讼等）
- 企业关系图谱
