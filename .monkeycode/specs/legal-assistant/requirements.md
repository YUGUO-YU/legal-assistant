# 法律助手小程序需求文档

## 1. 项目概述

### 1.1 项目名称
**法律助手 (LegalAssistant)**

### 1.2 项目目标
为律师和法律从业者提供一站式法律工作效率工具，涵盖法律文书起草、案例研究、法规查询、企业调查、案源发现等核心功能。

### 1.3 目标用户
- 执业律师
- 法律顾问
- 法务人员
- 法学研究者和学生

### 1.4 产品形态
- **微信小程序**：便捷移动端访问，支持即时查询和文书起草
- **Web 应用 (H5)**：跨平台网页端，适合桌面办公场景

### 1.5 技术架构
- **前后端分离**：独立前端 + 独立后端
- **数据库**：自建 MySQL/PostgreSQL
- **部署方式**：快速 MVP 验证

## 2. 功能模块

### 2.1 用户与权限系统

#### 2.1.1 用户认证
| 需求编号 | 需求描述 |
|---------|---------|
| USR-001 | 系统 SHALL 支持用户使用手机号+验证码进行注册和登录 |
| USR-002 | 系统 SHALL 支持微信一键登录（小程序端） |
| USR-003 | 系统 SHALL 支持邮箱+密码登录（Web端） |
| USR-004 | 系统 SHALL 支持找回密码功能（通过短信验证码） |
| USR-005 | 系统 SHALL 在用户登录成功后返回 JWT token，有效期 7 天 |

#### 2.1.2 权限管理
| 需求编号 | 需求描述 |
|---------|---------|
| USR-010 | 系统 SHALL 支持用户角色：管理员、律师、助理、访客 |
| USR-011 | 系统 SHALL 支持管理员创建和管理团队成员 |
| USR-012 | 系统 SHALL 支持基于角色的功能权限控制 |
| USR-013 | 系统 SHALL 支持律师用户创建和管理自己的案件 |

### 2.2 法律文书起草

#### 2.2.1 文书模板库
| 需求编号 | 需求描述 |
|---------|---------|
| DOC-001 | 系统 SHALL 提供常用法律文书模板库，包括：合同类、诉讼类、非诉类 |
| DOC-002 | 系统 SHALL 支持按文书类型、适用场景、行业领域进行模板筛选 |
| DOC-003 | 系统 SHALL 支持模板预览和分类搜索 |
| DOC-004 | 系统 SHALL 提供至少 50 份常用文书模板（MVP 阶段） |

#### 2.2.2 文书智能生成
| 需求编号 | 需求描述 |
|---------|---------|
| DOC-010 | 系统 SHALL 支持用户填写关键信息后自动生成文书草稿 |
| DOC-011 | 系统 SHALL 支持文书在线编辑（富文本编辑器） |
| DOC-012 | 系统 SHALL 支持文书保存为草稿或最终版本 |
| DOC-013 | 系统 SHALL 支持文书导出为 Word/PDF 格式 |
| DOC-014 | 系统 SHALL 记录文书历史版本，支持版本回溯 |

#### 2.2.3 文书管理
| 需求编号 | 需求描述 |
|---------|---------|
| DOC-020 | 系统 SHALL 支持用户管理自己创建的所有文书 |
| DOC-021 | 系统 SHALL 支持文书分类（按案件、按类型、按时间） |
| DOC-022 | 系统 SHALL 支持文书分享（生成链接或二维码） |

### 2.3 案例查询

#### 2.3.1 裁判文书检索
| 需求编号 | 需求描述 |
|---------|---------|
| CASE-001 | 系统 SHALL 支持关键词检索裁判文书 |
| CASE-002 | 系统 SHALL 支持按法院层级、案件类型、审理程序、地域进行筛选 |
| CASE-003 | 系统 SHALL 支持按判决日期、当事人、律师进行筛选 |
| CASE-004 | 系统 SHALL 支持法律文书全文检索 |
| CASE-005 | 系统 SHALL 支持检索结果分页展示，每页 20 条 |

#### 2.3.2 案例详情
| 需求编号 | 需求描述 |
|---------|---------|
| CASE-010 | 系统 SHALL 展示案例的基本信息（案号、法院、日期、当事人） |
| CASE-011 | 系统 SHALL 展示案例的完整裁判文书内容 |
| CASE-012 | 系统 SHALL 支持案例收藏和批注 |
| CASE-013 | 系统 SHALL 支持相似案例推荐 |

#### 2.3.3 案例分析
| 需求编号 | 需求描述 |
|---------|---------|
| CASE-020 | 系统 SHALL 提供案例的数据统计（按年份、按地区、按类型） |
| CASE-021 | 系统 SHALL 支持案例可视化图表展示 |

#### 2.4.2 法规详情

#### 2.4.3 法规订阅
| 需求编号 | 需求描述 |
|---------|---------|

## 3. 非功能性需求

### 3.1 性能需求
| 需求编号 | 需求描述 |
|---------|---------|
| PERF-001 | 系统 SHALL 保证页面加载时间不超过 3 秒 |
| PERF-002 | 系统 SHALL 支持至少 100 个并发用户（MVP 阶段） |
| PERF-003 | 系统 SHALL 保证检索结果返回时间不超过 2 秒 |

### 3.2 安全需求
| 需求编号 | 需求描述 |
|---------|---------|
| SEC-001 | 系统 SHALL 对用户密码进行加密存储（bcrypt） |
| SEC-002 | 系统 SHALL 对敏感操作（如文书导出）记录审计日志 |
| SEC-003 | 系统 SHALL 防止 SQL 注入和 XSS 攻击 |
| SEC-004 | 系统 SHALL 实现接口频率限制，防止滥用 |

### 3.3 兼容性需求
| 需求编号 | 需求描述 |
|---------|---------|
| COMP-001 | 系统 SHALL 支持 iOS 12.0 及以上版本 |
| COMP-002 | 系统 SHALL 支持 Android 8.0 及以上版本 |
| COMP-003 | 系统 SHALL 支持 Chrome、Safari、Firefox、Edge 最新版本 |

### 3.4 数据来源（MVP 阶段）
| 数据类型 | 数据来源策略 |
|---------|-------------|
| 裁判文书 | 对接北大法宝、OpenLaw 等公开数据 API |
| 法规数据 | 对接国家法规数据库、威科先行等公开数据 API |
| 企业工商 | 对接企查查、天眼查、爱企查等数据 API（需付费） |
| 企业风险 | 对接中国执行信息公开网等公开数据源 |
| 文书模板 | 自建模板库，逐步丰富 |

| 术语 | 定义 |
